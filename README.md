# 🎯 PlacementAI Predictor

An interactive web application designed to assess student profiles, estimate placement readiness, and deliver personalized skill recommendations.

---

## 🚀 Live Demo
🔗 [Launch PlacementAI](https://sanchitasam.github.io/placement-ai-predictor/)

---

## ✨ Features
- **Profile Evaluation:** Analyzes key inputs including academic performance, technical skills, and practical experience.
- **Dynamic Assessment:** Calculates placement readiness scores using client-side assessment logic.
- **Actionable Feedback:** Provides specific recommendations to help students target high-demand skills.
- **Responsive Layout:** Works smoothly across both mobile and desktop screens.

---

## 🛠️ Built With
- **HTML5:** Core markup and accessibility structure
- **CSS3:** Responsive styles, modern color palette, and component design
- **JavaScript (ES6):** Interactive scoring engine and dynamic DOM updates
